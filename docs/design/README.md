## ขอบเขต MVP

| MVP (v1) | ภายหลัง |
|---|---|
| ล็อกอิน Google + magic link · สมัครอิสระ | โพลโหวตลุค (แชร์ 2–4 ลุค) |
| Twin หลายท่า + guide + เช็กคุณภาพ | ดึงข้อมูลจากลิงก์ร้านอัตโนมัติ |
