# ADR-0003 — รูป twin เป็นส่วนตัวเสมอ แชร์ได้เฉพาะลุคผ่านลิงก์ที่เพิกถอนได้

**สถานะ:** ✅ Accepted · 2026-09-19 · แก้ 2026-09-19: เพิ่มข้อแอดมินไม่เห็นรูปลุค

## บริบท

รูปท่าคือรูปเต็มตัวของคนจริง — ข้อมูลส่วนบุคคลที่อ่อนไหวที่สุดในระบบ
แต่ผู้ใช้อยากถามเพื่อนว่า "ใส่ชุดไหนดี" แอปสมัครได้อิสระ จึงไม่มี "กลุ่ม" ที่ไว้ใจกันได้

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| ส่วนตัวทั้งหมด ไม่มีแชร์ | ปลอดภัยสุด | ถามความเห็นเพื่อนไม่ได้ |
| ระบบเพื่อน เห็น lookbook กัน | social | ต้องทำระบบเพื่อน · เปิดเผยเกินจำเป็น |
| **ส่วนตัวเป็นค่าเริ่มต้น แชร์ทีละลุคด้วยลิงก์ที่เพิกถอนได้** ✔︎ | ส่งต่อ LINE/IG ได้ทันที | ใครได้ลิงก์ก็ดูได้จนกว่าจะเพิกถอน |

## การตัดสินใจ

- รูปท่าเก็บใน storage แบบ private เท่านั้น เข้าถึงได้โดยเจ้าของ (และ pipeline AI ผ่าน URL อายุสั้น)
- **ไม่มีทางใดในระบบที่ทำให้คนอื่นเห็นรูปท่าได้** — รวมถึงหน้าแชร์ และหน้าแอดมิน
- **แอดมินไม่เห็นรูปลุคด้วย** (รูปลุคมีหน้าตาและรูปร่างของผู้ใช้) — รายการ 👎 แสดงแค่เหตุผล เลขลุค เวลา และสถิติ
  รูปลุคจึงเห็นได้แค่เจ้าของ และคนที่ถือลิงก์แชร์ที่เจ้าของสร้างเอง
- แชร์ได้เฉพาะ "รูปลุค" ทีละลุค ผ่านลิงก์ที่มี token เดาไม่ได้ เพิกถอนแล้วเปิดไม่ได้ทันที
- ผู้ใช้ลบ twin หรือข้อมูลทั้งหมดของตัวเองได้ทุกเมื่อ และการลบต้องลบไฟล์จริงใน storage

## ผลที่ตามมา

- หน้าแชร์ต้องไม่อ้างถึง ID ของท่าหรือของผู้ใช้
- ถ้าผู้ให้บริการ AI เก็บรูปไว้ต้องเลือกเจ้าที่ตั้งค่าไม่เก็บ/ลบได้ — เป็นเกณฑ์เลือกเจ้า
- ลบท่าแล้ว ลุคเดิมที่สร้างจากท่านั้นยังอยู่ (รูปลุคเป็นผลลัพธ์แยกไฟล์)

## ทบทวนเมื่อไหร่

เมื่อจะเพิ่มโพลโหวตหรือระบบเพื่อน — ต้องยังคงกฎ "ไม่มีใครเห็นรูปท่า"
