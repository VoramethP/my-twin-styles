# ADR-0002 — สมัครได้อิสระ คุมต้นทุนด้วยโควต้ารายคน + เพดานรวมทั้งระบบ

**สถานะ:** ✅ Accepted · 2026-09-19

## บริบท

ทุกการลองมีค่า AI จริง แอปเปิดให้ใครก็สมัครได้ (Google หรือ magic link)
คนเดียวจึงสมัครหลายบัญชีเพื่อหนีโควต้ารายคนได้ ยังไม่มีระบบรับเงิน

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| Invite code / allowlist | คุมต้นทุนง่ายสุด | ผู้ใช้ตัดสินใจแล้วว่าอยากเปิดอิสระ |
| โควต้ารายคนอย่างเดียว | ง่าย | หลายบัญชีทะลุงบได้ ไม่มีเพดานจริง |
| **โควต้ารายคน + เพดานรวมทั้งระบบต่อวัน** ✔︎ | งบต่อวันมีเพดานแน่นอน | วันที่คนใช้เยอะ ผู้ใช้ปกติโดนบล็อกไปด้วย |
| + เติมเครดิต/จ่ายเงิน | หารายได้ได้ | ใหญ่เกิน MVP |

## การตัดสินใจ

- ทุกการลองต้องผ่านการเช็ก **โควต้ารายคน** และ **เพดานรวม** ก่อนส่งไป AI
- บัญชีใหม่เริ่มโควต้าต่ำ แอดมินปรับรายคนได้ (ค่าตัวเลขอยู่ใน config ไม่อยู่ในเอกสารนี้)
- ระบบล้มเหลว (timeout / API error) → retry อัตโนมัติ 1 ครั้ง แล้ว **คืนโควต้า** ถ้ายังไม่สำเร็จ
- ผลออกมาแต่ไม่ถูกใจ (👎) → **ไม่คืนโควต้า** เพราะจะกลายเป็นช่องทางลองฟรีไม่จำกัด
- มีหน้าแอดมินเรียบง่าย: ผู้ใช้ · ยอดใช้วันนี้ · ปรับโควต้า · ตั้งเพดานรวม · รายการ 👎

## ผลที่ตามมา

- การนับโควต้าต้องเป็น atomic (กันกดรัว ๆ ทะลุ) และ "จอง" ตอนสั่งลอง ไม่ใช่ตอนได้ผล
- UI ต้องบอกโควต้าคงเหลือ และข้อความชัดเมื่อเพดานรวมเต็ม ("วันนี้เต็ม ลองใหม่พรุ่งนี้")

## ทบทวนเมื่อไหร่

เมื่อเพดานรวมเต็มบ่อยจนผู้ใช้ปกติบ่น หรือเมื่อจะเปิดระบบเติมเครดิต
