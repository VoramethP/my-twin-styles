# ADR-0004 — เป็น mobile-first web app แบบ PWA ไม่ทำ native app

**สถานะ:** ✅ Accepted · 2026-09-19

## บริบท

ผู้ใช้ถ่ายรูปท่าและชิ้นด้วยมือถือ และเปิดดู ref ตอนแต่งตัวหน้ากระจก
การลองทำงานเบื้องหลัง จึงต้องแจ้งเตือนเมื่อเสร็จ

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| Native app (iOS/Android) | push เสถียร กล้องดี | ต้องผ่าน store สองที่ ดูแลสองโค้ดเบส |
| Desktop-first web | ทำง่าย | ไม่ตรงกับจังหวะที่ใช้จริง |
| **Mobile-first web + PWA** ✔︎ | โค้ดเบสเดียว แชร์ลิงก์เปิดได้ทันที | iOS ส่ง Web Push ได้ต่อเมื่อ "เพิ่มไปที่หน้าจอโฮม" แล้วเท่านั้น |

## การตัดสินใจ

ออกแบบทุกหน้าที่ความกว้างมือถือก่อน (bottom tab 4 แท็บ)
แจ้งเตือนในแอปเสมอ + Web Push เมื่อติดตั้ง PWA แล้ว
ชวนติดตั้ง PWA **หลังการลองครั้งแรก** ไม่บังคับตั้งแต่เริ่ม
หน้าแอดมินเป็นข้อยกเว้นเดียวที่ออกแบบสำหรับเดสก์ท็อป

## ผลที่ตามมา

- ผู้ใช้ iOS ที่ไม่ติดตั้ง PWA จะรู้ว่าลองเสร็จเมื่อเปิดแอปเท่านั้น — UI ต้องแสดงการลองที่ค้างอยู่ชัดเจน
- UI ภาษาไทยเป็นหลัก แต่ข้อความต้องผ่านระบบ i18n ตั้งแต่แรก (เตรียมภาษาอังกฤษ)

## ทบทวนเมื่อไหร่

เมื่อ push บน iOS เป็นปัญหาหลักของการกลับมาใช้ หรือเมื่อต้องใช้ความสามารถกล้องที่เว็บทำไม่ได้
